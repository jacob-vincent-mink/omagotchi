# Omagotchi credits

## Sound effects

The clips in `sounds/` are placeholders, reused from the sound library of the
[tomato-timer](https://github.com/SLcode777/tomato-timer) plugin. Each file is
named after the pet event it plays for, so better-fitting sounds can be
dropped in without touching code. Original sources (freesound.org):

| File | Event | Source |
| --- | --- | --- |
| `hatch.mp3` | egg hatches | "Level Up 01" by mokasza — https://freesound.org/s/810753/ — CC BY 4.0 |
| `evolve.mp3` | evolution | "game-win.mp3" by mickleness — https://freesound.org/s/269198/ — CC0 |
| `eat.wav` | feeding | "Confirm Beeps (No Delay)" by SilverIllusionist — https://freesound.org/s/664262/ — CC BY 4.0 |
| `wash.mp3` | scrubbed clean | "bell.mp3" by DavidKronberg — https://freesound.org/s/591446/ — CC0 |
| `pet.mp3` | petting | "Short Success Sound Glockenspiel" by FunWithSound — https://freesound.org/s/456965/ — CC0 |
| `sleep.wav` | falling asleep | "[UI Sound] Approval — High Pitched Bell Synth" by GabFitzgerald — https://freesound.org/s/625174/ — CC0 |
| `stun.wav` | stunned by a big fall | "Old Video Game 4" by sonically_sound — https://freesound.org/s/624878/ — CC BY 4.0 |
| `farewell.wav` | the adult flies home | "Happy ending" by avreference — https://freesound.org/s/571177/ — CC0 |
